# 🏡 Well – Villa & Room Booking Platform

Stify is a modern and elegant villa & room booking platform designed to provide users with a smooth and seamless booking experience.
Users can explore premium stays, check availability, view detailed property information, and manage listings easily.

Built with a clean UI, responsive design, and powerful backend functionality.

# ✨ Features

## 🔍 User Features

* Browse beautiful villas and rooms
* Explore detailed property pages
* Check pricing, location, ratings, and descriptions
* Responsive design for mobile, tablet, and desktop
* Smooth and user-friendly navigation

---

## 👤 Logged-In User Features

* Book rooms easily
* Add new property listings
* Edit and update own listings
* Delete own listings
* Manage personal content securely

---

## 👑 Admin Features

* Manage all listings
* Monitor bookings
* Remove inappropriate or spam listings
* Maintain platform quality

# 🚀 Installation & Setup

Clone the repository:

```bash id="9af3pr"
git clone https://github.com/manu8057/well-Project.git
```

Move into the project directory:

```bash id="cx7d0m"
cd well-Project
```

Install dependencies:

```bash id="m2q8zs"
npm install
```

Run the server:

```bash id="h4t1kn"
node app.js
```
